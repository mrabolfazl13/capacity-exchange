# UI/UX Specification

## Principles
- modern
- polished
- responsive
- fast
- accessible
- information-dense without feeling crowded
- clear hierarchy
- meaningful empty/loading/error states

## Desktop
Tauri + React + TypeScript.

Primary areas:
- Marketplace
- Search
- Capacity detail
- Bookings
- Messages
- Provider workspace
- Analytics
- Admin

## Mobile
Flutter:
- discovery
- search
- capacity detail
- booking
- orders
- notifications
- provider quick actions

## Provider Capacity Wizard
1. category
2. resource
3. capacity definition
4. location
5. availability
6. pricing
7. rules
8. photos/documents
9. preview
10. publish

Do not use generic CRUD forms when a task-specific wizard materially improves usability.

## UX QA
Check typography, spacing, hierarchy, loading states, errors, keyboard behavior, touch targets, responsiveness, accessibility, and consistency.
