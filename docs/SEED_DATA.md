# Seed Data

Create realistic demo data.

Minimum:
- 5 organizations
- 15 providers
- 50 customers
- 50 capacity resources
- 100 offers
- recurring and one-off availability
- 100 demand requests
- bookings in multiple states
- orders
- reviews
- notifications

Use multiple capacity categories:
- meeting room
- warehouse
- parking
- equipment
- appointment slot
- truck return capacity
- commercial kitchen
- production slot

Seed data must demonstrate real marketplace behavior, not random meaningless rows.
