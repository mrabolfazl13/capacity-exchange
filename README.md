# Capacity Exchange — Qoder Project Pack

This directory contains the complete project specification package for building Capacity Exchange with Qoder/Kilo-style autonomous agents.

## Start

1. Open the repository in Qoder.
2. Read `MASTER_PROMPT.md`.
3. Read `AGENTS.md`.
4. Read `CURRENT_STATE.md`.
5. Execute the implementation plan.
6. Keep the state and documentation synchronized.

## Stack

- Tauri + Vite + React + TypeScript
- Flutter Android/iOS
- FastAPI
- PostgreSQL
- Redis
- Celery
- Docker

## Principle

Build real, testable, integrated software. Do not stop at plans or mockups.
